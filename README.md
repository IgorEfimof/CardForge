# 🛠️ CardForge

**CardForge** — это браузерная студия для создания профессиональных карточек товаров для маркетплейсов. 

Инструмент позволяет собрать инфографику, настроить типографику и (при наличии собственного API) заменить фон товара с помощью нейросетей. Весь процесс рендеринга и обработки происходит локально в браузере, что гарантирует скорость и приватность данных.

## 🚀 Основные возможности
- **Работа с изображениями**: Загрузка нескольких фото товара, выбор основного, масштабирование и позиционирование.
- **AI-замена фона**: Интеграция с внешним AI-сервисом (через API) для удаления старого фона и генерации нового (студия, интерьер, премиум, природа или свой промпт).
- **Гибкая типографика**: Настройка названия, подзаголовка, списка преимуществ, акцентной плашки и нижнего колонтитула.
- **Шаблоны и стили**: Три готовые цветовые темы (Light, Dark, Warm), выбор формата (3:4, 4:5, 1:1, 2:3), настройка акцентного цвета и масштаба элементов.
- **Экспорт в высоком качестве**: Сохранение готовой карточки в PNG с возможностью выбора разрешения.
- **Локальное сохранение**: Проекты сохраняются в LocalStorage браузера, что позволяет вернуться к редактированию позже без потери данных.

## ⚙️ Как запустить локально
Проект не требует сборки, серверной части или установки зависимостей.
1. Скачайте файлы репозитория или откройте проект через GitHub Pages.
2. Откройте файл `index.html` в любом современном браузере.
3. Загрузите фото и настройте карточку. 

> **Примечание по AI**: Функция замены фона требует указания адреса вашего собственного совместимого backend-сервиса (с эндпоинтами `/remove-background` и `/generate-background`). Без этого карточка отлично работает в режиме ручной сборки с готовыми шаблонами.

## 🛠️ Технологии
- HTML5, CSS3 (CSS-переменные, Grid/Flexbox, адаптивная вёрстка, тёмная тема)
- Нативный JavaScript (ES6+)
- Canvas API для высокопроизводительного рендеринга макетов и экспорта
- LocalStorage для управления состоянием и сохранения проектов
- *Отсутствие фреймворков и систем сборки: максимальная лёгкость и чистота кода.*
